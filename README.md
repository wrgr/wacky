# Wackywords

A colorful mobile-first fill-in-the-blank story game for kids and adults.

## Play

After GitHub Pages is enabled, the game will be available at:

https://wrgr.github.io/wacky/

## What is included

- Kid and adult vocabulary modes
- An editable cast of up to 10 characters
- 10 themed, prewritten stories
- Color- and symbol-coded names, actions, modifiers, and miscellaneous words
- Coherent word suggestions plus custom answers
- A responsive, dependency-free static site

The published game is built directly from the files in `dist/`.
